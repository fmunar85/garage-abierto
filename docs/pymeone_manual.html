1. Acceso al sistema

/login

Para ingresar necesitás un usuario y contraseña que te proporciona el administrador. PymeOne maneja dos roles:

👑
Administrador
Acceso total: ventas, inventario, reportes, usuarios, configuración del sistema.
🏪
Vendedor
Registrar ventas, consultar stock y productos, gestionar clientes.
  1. Abrí el navegador (Chrome, Edge, Firefox, Safari) en cualquier dispositivo.
  2. Ingresá la dirección web del sistema y tu email y contraseña.
  3. Hacé click en "Iniciar sesión". Serás redirigido al panel principal.
💡Si olvidaste tu contraseña, contactá al administrador para que la restablezca desde Administración → Usuarios → Editar.
📊

3. Inventario

/inventario/

3.1 Alta de un producto nuevo

  1. Andá a Inventario → Nuevo producto.
  2. Completá los campos obligatorios: SKU, Nombre, Categoría, Precio de venta.
  3. Completá opcionales recomendados: Marca, Proveedor, Precio de costo (para margen bruto), Stock inicial, Stock mínimo.
  4. Subí una foto del producto — desde computadora o cámara del celular. Se guarda automáticamente en la nube.
  5. Hacé click en "Guardar producto".
ℹ️El SKU es el código único por producto. Debe ser distinto para cada artículo. Ejemplo: ZAP001, CAM003. Con él buscás y facturás rápido.

3.2 Editar y ajustar stock

En la tabla de inventario, hacé click en ✏️ para editar precio, stock, imagen o cualquier dato. Los cambios se aplican en tiempo real.

⚠️Bajá el stock manualmente solo para ajustes reales (rotura, merma, diferencia de conteo). Las ventas descuentan el stock automáticamente.

4. Códigos de barras por unidad física

/inventario/codigos-barras

PymeOne genera un código de barras único de 16 dígitos por cada unidad física que ingresa al depósito. Trazabilidad completa de cada artículo desde que entra hasta que se vende.

Estructura del código

CATSUPPRODSECUENCIA 3 dígitos (cat.) · 3 dígitos (prov.) · 4 dígitos (prod.) · 6 dígitos (secuencia global) = 16 total

Cómo ingresar unidades nuevas

  1. Entrá a Inventario → Códigos de barras.
  2. Hacé click en el botón verde "Ingresar unidades".
  3. Seleccioná la Categoría. La lista de productos se filtra sola.
  4. Elegí el Producto del listado filtrado.
  5. Ingresá la cantidad de unidades a recibir (1 a 999).
  6. Hacé click en "Generar códigos". El sistema crea un barcode único para cada unidad y los muestra listos para imprimir.
🖨️Para imprimir los barcodes, usá Ctrl+P. Son formato CODE128, compatibles con cualquier lector de código de barras estándar.

Estados de una unidad

EstadoSignificado
disponibleLa unidad está en stock, lista para vender.
vendidaFue asignada a una venta completada.
dañadaMarcada como dañada o fuera de uso.

5. Ventas

/ventas/

5.1 Registrar una venta nueva

  1. Andá a Ventas → Nueva venta.
  2. Escribí en el buscador el nombre, SKU o marca del producto (mínimo 2 caracteres). Aparecen sugerencias al instante.
  3. Seleccioná el producto. Se agrega al carrito con cantidad 1. Cambiá la cantidad con + / − o editando el número.
  4. Para agregar un descuento, ingresá el porcentaje (ej: 10 = 10% de descuento).
  5. Seleccioná el método de pago: Efectivo, Débito, Crédito, Transferencia u Otro.
  6. Opcionalmente vinculá un Cliente y agregá notas.
  7. Hacé click en "Registrar venta". El stock se descuenta automáticamente y se genera el comprobante.
⚡Si tenés un lector de código de barras, podés escanear directamente el barcode de 16 dígitos para agregar el producto al carrito al instante.

5.2 Historial y filtros

La pantalla de ventas muestra todas las transacciones. Filtrá por estado (completada/cancelada), método de pago y rango de fechas.

5.3 Cancelar una venta

Desde el detalle de la venta, el admin puede cancelarla. Al cancelar, el stock de todos los artículos se restaura automáticamente.

⚠️Solo Admin Solo un administrador puede cancelar ventas.

6. Clientes

/clientes/
  • ➕
    Agregar cliente
    Nombre, email, teléfono y dirección. El email es opcional pero recomendado.
  • ✏️
    Editar datos
    Actualizá cualquier campo desde el botón de edición en la tabla.
  • 📋
    Historial de compras
    Desde el detalle del cliente podés ver todas las ventas realizadas.
  • 🔴
    Desactivar cliente
    Un cliente inactivo no aparece en el selector de ventas, pero conserva su historial.

9. Pantalla de exhibición (Display)

/display/

Pantalla pública diseñada para un monitor o TV orientada al cliente. No requiere login.

  • 🏷️
    Catálogo en tiempo real
    Muestra todos los productos activos con imagen, nombre y precio actualizado automáticamente.
  • ⭐
    Ticker de productos destacados
    Cinta animada en la parte superior que desplaza a velocidad constante los productos marcados como "Destacado" con su precio.
  • 🔍
    Modal de detalle
    El cliente puede hacer click en cualquier producto para ver imagen ampliada, descripción y precio.
💡Para que un producto aparezca en el ticker, activá el checkbox "Destacado" en la ficha del producto. Podés destacar tantos como quieras.
⚙️

10. Administración del sistema

10.1 Gestión de usuarios Solo Admin

  1. Andá a Administración → Usuarios → Nuevo usuario.
  2. Completá nombre, email (será el usuario de login), contraseña y rol (admin o vendedor).
  3. Para cambiar contraseña: editá el usuario y completá "Nueva contraseña". Si lo dejás vacío, no cambia.
  4. Para deshabilitar sin eliminar: desmarcá "Activo". El historial de ventas queda intacto.
⚠️No podés eliminar tu propia cuenta. Si necesitás hacerlo, pedile a otro administrador.

10.2 Imágenes de productos

Las imágenes se almacenan en la nube (Cloudinary). No se pierden aunque el servidor se reinicie.

  • Al cargar una imagen en el formulario, se sube automáticamente.
  • Desde celular, el botón de imagen abre la cámara directamente.
  • Formatos soportados: JPG, PNG, GIF, WEBP.

10.3 Promociones bancarias

Cargá las promociones vigentes (cuotas sin interés, descuentos con tarjeta). Aparecen destacadas en el dashboard para que el equipo de ventas las tenga presentes al atender.
