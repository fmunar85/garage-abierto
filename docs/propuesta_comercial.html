Preguntas frecuentes

¿Necesito computadora propia para usarlo?
No. El sistema funciona desde cualquier dispositivo con internet: PC, notebook, tablet o celular. No requiere instalación.
¿Qué pasa si se va internet?
Como todo sistema web, requiere conexión a internet para funcionar. Recomendamos tener una conexión de respaldo (datos móviles) para casos de corte.
¿Cuántos usuarios puedo tener?
Usuarios ilimitados. Podés tener 2 o 20 empleados usando el sistema al mismo tiempo sin costo adicional.
¿Mis datos están seguros?
Sí. La base de datos está en Railway (infraestructura de Amazon AWS), con backups automáticos. Las imágenes están en Cloudinary (redundancia geográfica). Conexiones cifradas con HTTPS.
¿Puedo agregar funcionalidades a medida?
Sí. El sistema fue construido modularmente. Podemos agregar integración con MercadoPago, reportes de AFIP, notificaciones por WhatsApp, o cualquier otra necesidad específica de tu negocio.
¿Qué pasa si decido no renovar el mantenimiento?
El sistema sigue funcionando. El mantenimiento no es obligatorio, pero sin él el hosting y los backups corren por tu cuenta. Te entregamos toda la documentación técnica para que otro desarrollador pueda continuarlo.
