Preguntas frecuentes

¿Necesito computadora propia para usarlo?
No. Funciona desde cualquier dispositivo con internet: PC, notebook, tablet o celular. No requiere instalación ni configuración.
¿Qué pasa si se va internet?
Como todo sistema web requiere conexión. Recomendamos tener una conexión de respaldo (datos móviles) para casos de corte.
¿Cuántos usuarios puedo tener?
Usuarios ilimitados. Podés tener 2 o 20 empleados operando simultáneamente sin costo adicional.
¿Mis datos están seguros?
Sí. La base de datos está en Railway (infraestructura Amazon AWS) con backups automáticos. Las imágenes en Cloudinary con redundancia geográfica. Conexión HTTPS cifrada.
¿Puedo agregar funcionalidades a medida?
Sí. El sistema fue construido modularmente. Podemos agregar integración con MercadoPago, reportes para AFIP, WhatsApp, o cualquier necesidad específica de tu rubro.
¿Qué pasa si no renuevo el mantenimiento?
El sistema sigue funcionando. El mantenimiento no es obligatorio, pero el hosting y backups quedan a tu cargo. Entregamos toda la documentación técnica para que otro desarrollador pueda continuarlo.
