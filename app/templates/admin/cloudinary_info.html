¿Por qué necesitamos esto?

Railway (donde está hosteada esta app) usa contenedores efímeros: cada vez que se hace un deploy o Railway reinicia el servidor, el sistema de archivos se resetea. Cualquier imagen subida manualmente se pierde.

La solución es usar Cloudinary — un servicio de almacenamiento de imágenes en la nube. El plan gratuito incluye 25 GB de almacenamiento y 25.000 transformaciones/mes, más que suficiente para esta app.

Configurar Cloudinary en Railway — paso a paso
  1. Crear cuenta gratuita en Cloudinary
    Ir a cloudinary.com/users/register_free y registrarse con email o Google.
  2. Copiar las credenciales
    En el dashboard de Cloudinary (sección Product Environment) vas a ver:
    • Cloud name
    • API Key
    • API Secret
  3. Agregar variables en Railway
    En tu proyecto de Railway → Variables → agregar:
    CLOUDINARY_CLOUD_NAME = tu-cloud-name
    CLOUDINARY_API_KEY = 123456789012345
    CLOUDINARY_API_SECRET = abcdefghijklmnopqrstuvwxyz
  4. Railway redeploya automáticamente
    Al guardar las variables, Railway reinicia la app. Recargá esta página y deberías ver el estado ✅ Cloudinary activo.
  5. Listo — al subir una imagen desde el formulario de producto (desde PC o celular), se sube directamente a Cloudinary y queda guardada para siempre.
Uso desde celular

El formulario de producto tiene el atributo capture="environment" en el campo de imagen, lo que en celulares Android/iOS muestra la opción de tomar foto con la cámara trasera directamente o elegir de la galería.

Con Cloudinary configurado, la foto se sube a la nube al guardar el producto. Sin Cloudinary, queda temporalmente en el servidor.

Alternativa: usar URL de imagen externa

Si no querés configurar Cloudinary, podés subir las fotos a cualquier servicio externo y pegar la URL en el campo "O pegar URL de imagen" del formulario:

  • Google Photos → compartir → "Cualquiera con el enlace" → copiar URL directa
  • Imgur (imgur.com) → subir imagen → copiar enlace directo (.jpg)
  • ImgBB (imgbb.com) → gratuito, sin registro para imágenes básicas
  • El sitio del proveedor → muchas veces tienen fotos de productos en su web
